# Runtime content

`content/tuning/` and `content/definitions/` contain the typed product configuration loaded through
Engine content services. `content/art/generated/` and `content/audio/` contain runtime assets.
Editable art recipes, supplied references and comparison experiments live in
`docs/art/`; they are not staged as product content.

See [gameplay ownership](gameplay-design.md) for consumers and validation.
Save before changing watched content if the live run matters.
