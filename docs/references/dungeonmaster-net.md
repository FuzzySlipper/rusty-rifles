# DungeonMaster.NET source map

Repository: `/home/research/blobber-games/DungeonMaster.NET`. The README describes a C#/.NET Dungeon Master reimplementation; its parser is a helper for original data. Treat this as semantic evidence for a conventional real-time grid blobber. It is not a Rifles dependency or architecture to copy.

## Strong entry points

1. **Bootstrap, tick, and visibility.** [`Engine.LoadContent` and `Engine.Update`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Engine.cs) build `DungeonParser` -> `LegacyFactories` -> `LegacyLeader` -> `LegacyMapBuilder` -> `Dungeon`, then call `DungeonBase.Update`. [`DungeonBase.Update` and `UpdateVisibleTiles`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/DungeonBase.cs) update the leader, every active level, light, and a tile BFS visibility set. Adapt the lifecycle boundary to Rusty Engine admitted time; keep dungeon policy in C#.

2. **One party cell and cardinal orientation.** [`PointOfViewCamera.GetTranslation`, `MoveToAsync`, and `SetMapDirection`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Player/PointOfViewCamera.cs) convert forward/back/left/right input to one tile shifts and retain `MapDirection`. [`LegacyLeader.MoveToAsync`, `MovePartyAsync`, `RotateParty`, and `RotatePartyPiOver2`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Player/LegacyLeader.cs) move all champions and rotate their four subcell positions. Preserve this party-facing invariant while routing input through the Engine.

3. **Footprints, occupancy, and shared cells.** [`LayoutManager<TItem>.IsFree`, `TryGetSpace`, `GetEntities`, and `FreeSpace`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Entity/GroupSupport/Base/LayoutManager.cs) reserve spaces by rectangle intersection. [`Small4GroupLayout.GetToNeighbour` and `GetToSide`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Entity/GroupSupport/Small4GroupLayout.cs) search within a tile and bridge neighboring tiles. [`LegacyFactories.GetGroupLayout`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Builders/LegacyFactories.cs) maps creature size to small-fourth or full-tile layouts; size 1 is an explicit half-tile TODO fallback. Adopt authored footprint/occupancy semantics, with a product-owned representation.

4. **AI on the same grid.** [`Creature.LiveAsync`, `FindEnemies`, `MoveThroughSpaces`, `Hount`, and `PrepareForFight`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Entity/Creature.cs) poll watch/home/hunt states, use tile `BreadthFirstSearch.GetShortestRoute`, then use the creature layout to traverse intra-tile spaces before `CreatureAttack.Apply`. [`BreadthFirstSearch<TTile,TBundle>`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Helpers/BreadthFirstSearch.cs) records predecessor routes and bounded distance. Keep navigation and combat on the same grid; add explicit line-of-sight, costs, and ranged decisions in Rifles.

5. **Action timing and melee.** [`LegacyFactories.GetFightActionsFactories` and `GetComboActions`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Builders/LegacyFactories.cs) turn data descriptors into swing, melee, throw, and combo actions. [`HumanAttack.Apply`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Actions/HumanAttack.cs) applies stamina/skill/experience costs and delegates to [`MeleeAttack.F402_xxxx_MENUS_IsMeleeActionPerformed` and `F231_izzz_GROUP_GetMeleeActionDamage`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Actions/MeleeAttack.cs). `Creature.PrepareForFight` uses the same adjacent-space route. The donor returns fatigue-like delays but has no authoritative scheduler; make timing policy a C# contract over Engine time.

6. **Ranged items as moving world objects.** [`ThrowAttack.Apply`, `F328_nzzz_CHAMPION_IsObjectThrown`, and `F212_mzzz_PROJECTILE_Create`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Actions/ThrowAttack.cs) remove a hand item, spend stamina, and create an `ImpactProjectile` with `ThrowImpact` or `WeaponImpact`. [`Projectile.Run`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Projectiles/Projectile.cs) advances space-by-space; [`ImpactProjectile.F217_xxxx_PROJECTILE_HasImpactOccured`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Projectiles/ImpactProjectile.cs) selects occupants, and `ThrowImpact.FinishImpact` returns the item to the impact location. This is the strongest donor model for first-class ranged actions; define range, blockers, and damage policy locally.

7. **Floor items and typed inventory.** [`FloorTileSide` and `FloorItemStorage.Trigger`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Tiles/Sides/FloorTileSide.cs) and [`/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Tiles/Renderers/FloorItemStorage.cs`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Tiles/Renderers/FloorItemStorage.cs) maintain four floor spaces and hand pickup/drop; `FloorTileSideRenderer.Interact` supplies the ray hit. [`Inventory.AddItem`, `AddItemTo`, and `TakeItemFrom`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Entity/BodyInventory/base/Inventory.cs) enforce storage compatibility through item factories. Preserve world-location transitions, but use Rifles content records and save meaning.

8. **Spell sequence to effect.** [`SpellCastingManager.TryBeginCastSpell`, `TryCastSymbol`, and `TryCastSpell`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Magic/SpellCastingManager.cs) charge mana, match `ISpellFactory.CastingSequence`, and run the spell in `Entity.MapDirection`. [`SpellFactory.CastSpell`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/DungeonContent/Magic/Spells/Factories/SpellFactory.cs) gates by skill/wisdom; `ProjectileSpell.Run` -> `Projectile.Run`, while [`LegacySpellCreator.GetSpell`](/home/research/blobber-games/DungeonMaster.NET/src/DungeonMasterEngine/Builders/LegacySpellCreator.cs) selects explosion, potion, torch, or door effects. Adopt sequence/resource/effect semantics; define spells in validated `content/` records instead of direct HTML reads.

## Gaps and boundaries

The donor is incomplete evidence: `Medium2GroupLayout` methods, `SpellFactoryMocap.ApplySpellEffect`, `OtherSpell.Run`, and projectile `MoveTo`/`MoveToAsync` throw; `RemoteCreatureAttack.Apply` is effectively a stub. `Creature.LiveAsync` uses `async void`, a static BFS, and a 100 ms polling loop. `DungeonParser.Parse`, `DungeonData`, and `LegacySpellCreator` read binary/HTML files directly from the process directory. These are missing concepts or hazards to resolve, not APIs to import.
